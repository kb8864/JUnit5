## 同値分割とは入力を「アウトプットが同じになるようなグループ」に分けて、各グループから代表値だけテストしてムダを減らす。

<details><summary>コード</summary>

```python
print('Hello world!')
```　
</details>

* 例：年齢入力の仕様

  * 未成年：0–19 はエラー
  * 成人：20–64 はOK
  * 高齢：65–120 はOK
    → グループ（= 同値クラス）

    * エラー群：0–19
    * OK群A：20–64
    * OK群B：65–120
      → テストは**代表値**だけ：19 / 20 / 65

**ポイント**

* 連続範囲は1つの“同値クラス”。
* クラスごとに1〜2個選べば、ほぼ同じ動作を何十個も試すムダが消える。
* **正常系と異常系**どちらも分ける（無効同値クラスも忘れない）。

# 境界値分析（Boundary Value Analysis）

**ねらい**：**切り替わり点の前後**でバグが出やすいので、**境界±1**を重点的に試す。

* 例：送料が「5,000円未満は0円、5,000〜9,999円は5%、10,000円以上は10%」

  * 境界は **0 / 5,000 / 10,000**
  * 試す値は **4,999 ↔ 5,000**, **9,999 ↔ 10,000**（ついでに -1 と 0）

**ポイント**

* 条件が `<` か `<=` かで**ちょうど境界**の扱いが変わる。
* 「一番小さい」「一番大きい」も境界。
* 浮動小数や日時は**刻み幅**（小数点、ミリ秒）に注意。

---

## 同値分割 × 境界値：どう組み合わせる？

1. 仕様から**区間（同値クラス）**に分ける
2. 各クラスの**代表値**を選ぶ（1〜2個）
3. クラス間の**境界の前後**を1組ずつ追加
   → **少数のテストで“広く深く”検査**できる

---



## よくある落とし穴

* 代表値ばかりで**境界前後を忘れる**
* 正常クラスだけ見て**異常クラス（無効値）を作らない**
* “範囲が複数重なる”仕様で**境界の定義が曖昧**（`<` と `<=` を混同）
